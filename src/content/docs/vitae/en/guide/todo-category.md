Todos can be organized by category too. You can <strong>enable / disable</strong> the built-in categories to keep only the ones you need, or <strong>create your own categories</strong>—give each a name and pick a color—so when you jot down a todo you can file it under that category and tell them apart at a glance in the list.

## Steps

1. <strong>Open category management</strong>. Path: <strong>Settings → Todo → Category Management</strong>, where you can enable / disable categories and add custom ones.
2. <strong>Enable / disable categories</strong>. Turn a category's switch off and it won't show up when creating a new todo; turn it back on when you need it.
3. <strong>Add a category</strong>. Tap <strong>"Add Category"</strong>, enter a category name (for example "Work Tasks"), then tap <strong>"Next"</strong>.
4. <strong>Pick a color</strong>. Choose a color for the category (used to tell them apart in the list), then tap <strong>"Done"</strong> to save.
5. <strong>Start using it</strong>. The new category is available right away, so you can select it when jotting down a todo.

## FAQ

### If I disable a category, will the todos already filed under it be lost?

No. Disabling only stops it from <strong>showing up when creating a new todo</strong>; existing todos and records are all still there. Re-enable it and you can use it again.

### Can I change a category's color or name?

Yes. Go back to <strong>Settings → Todo → Category Management</strong> and open the category to rename it or change its color.

### Can I delete a custom category?

Yes. Just delete it in category management. If you're worried about affecting todos you've already logged, you can also just <strong>disable</strong> it instead of deleting.

### How do I assign a category to a todo?

Just select a category when creating or editing a todo; with voice quick capture, the AI also determines the category automatically—see [Voice Quick Capture for Todos](/en/vitae/guide/todo-voice/).
