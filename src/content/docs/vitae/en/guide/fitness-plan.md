Fitness starts from the <strong>Exercise</strong> tab at the bottom of the Health module. First <strong>build a workout into a plan</strong>—add exercises and set the sets, reps, and weight for each; when it's time to train, just <strong>start the workout</strong>, log set by set, and after each set a <strong>rest countdown starts automatically</strong> to remind you when to begin the next set.

## Step 1: Build a Training Plan

1. <strong>Manage plans</strong>: go to <strong>Health → Exercise</strong> and open plan management from the right side of the plan card’s heading to create or edit a plan.
2. <strong>Name and exercises</strong>: name the plan, add exercises, and set target sets, reps, weights and other values.
3. <strong>Training days</strong>: choose one schedule type in the plan editor: <strong>weekdays / days of the month / specific calendar dates</strong>. Plans do not use rotating schedules.
4. <strong>Save</strong>: plans scheduled for today appear first under <strong>Today’s Plan</strong>. Otherwise, Exercise highlights the recent plan to <strong>repeat</strong>; other plans and free training share the same card.

## Step 2: Start the Workout, Log Set by Set

1. <strong>Start training</strong>: choose today’s plan, repeat a recent plan, or start free training.
2. <strong>Log in the set table</strong>: sets are prefilled with your last results. Adjust the weight, reps, duration or distance to match this workout, then mark each set complete. Prefilling does not confirm a set for you.
3. <strong>Rest between sets</strong>: finishing a set starts a countdown. Use <strong>−15s / +15s</strong> during training to adjust it. The final set does not start another rest.
4. <strong>Add or remove sets</strong>: adjust the number of sets to match your workout.

## FAQ

### Can I change the rest timer length? What if I don't want reminders?

Yes. In <strong>Settings → Health</strong>, choose a preset default rest time from <strong>30–240 seconds</strong>. The default is 120 seconds if unchanged, and you can adjust it by 15 seconds at a time during training. To disable rest-end notifications, turn off <strong>Rest End Reminder</strong> on the same settings page.

### Can I reuse this plan next time?

Yes. Saved plans stay in Exercise, and recent plans are ready to <strong>repeat</strong> without rebuilding them.

### Can I fix a set I logged wrong?

Yes. Edit the actual results in the set table or delete extra sets. These changes only affect this workout’s record.

### The library doesn't have the exercise I want?

You can create your own. See [Exercise Library & Custom Exercises](/en/vitae/guide/fitness-library/) for details.
