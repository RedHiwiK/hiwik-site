Fitness starts from the <strong>Exercise</strong> tab at the bottom of the Health module. First <strong>build a workout into a plan</strong>—add exercises and set the sets, reps, and weight for each; when it's time to train, just <strong>start the workout</strong>, log set by set, and after each set a <strong>rest countdown starts automatically</strong> to remind you when to begin the next set.

## Step 1: Build a Training Plan

1. <strong>Create a plan</strong>. Go to <strong>Health → Exercise</strong> and create a new training plan.
2. <strong>Name it, note the focus</strong>. Give the plan a name (e.g. "Monday Plan"), then write a line about its focus (e.g. "Chest / Shoulders / Triceps - Monday Push") so it's easy to recognize later.
3. <strong>Add exercises</strong>. Tap the <strong>"+"</strong> in the top right to pick exercises from the library (e.g. barbell flat bench press). The top bar shows the <strong>number of exercises added, total sets, and estimated duration</strong> in real time.
4. <strong>Set sets / reps / weight</strong>. Open an exercise and set the <strong>sets</strong> (3 / 4 / 5 / 6), <strong>reps</strong> (8 / 10 / 12 / 15), and <strong>weight</strong> (10 / 20 / 30 / 40kg)—tap a preset or fine-tune with "−／＋", then tap <strong>"Confirm"</strong>.
5. <strong>Save the plan</strong>. Once everything is set, tap the <strong>green checkmark</strong> in the top right to save. A draft with no exercises added is discarded automatically when you exit.

## Step 2: Start the Workout, Log Set by Set

1. <strong>Start an exercise</strong>. Open an exercise and tap <strong>"Start Exercise"</strong>; the top shows progress like "0/4 completed".
2. <strong>Log each set</strong>. After each set, enter the actual <strong>weight and reps</strong> for that set and tap <strong>"Finish Set"</strong>. To reuse the previous set's data, tap <strong>"Same as Last Set"</strong> to fill it in instantly.
3. <strong>Automatic rest reminder</strong>. After finishing a set, a <strong>2-minute rest countdown starts automatically</strong> (currently fixed at 2 minutes), and a notification reminds you when it's time for the next set. To turn reminders off, see the FAQ below.
4. <strong>Add or remove sets</strong>. Want to do more or fewer sets on the fly? Add a set, or <strong>long-press a set</strong> to delete it.

## FAQ

### Can I change the rest timer length? What if I don't want reminders?

The rest length is currently <strong>fixed at 2 minutes</strong> and can't be customized yet; adjustable durations are coming in a later version. If you don't want reminders, go to <strong>Settings → Health</strong> and turn off the <strong>"Rest End Reminder"</strong> switch.

### Can I reuse this plan next time?

Yes. A saved plan stays in "Exercise"; next time just open it and tap <strong>"Start Exercise"</strong> to train—no need to rebuild it.

### Can I fix a set I logged wrong?

Yes. Open the set in question and re-enter the weight and reps; long-press to <strong>delete</strong> extra sets. These changes only affect this workout's record.

### The library doesn't have the exercise I want?

You can create your own. See [Exercise Library & Custom Exercises](/en/vitae/guide/fitness-library/) for details.
