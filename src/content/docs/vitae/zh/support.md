## 常见问题

### 我的数据安全吗？

安全。平生不会把你的业务数据存到我们的服务器上，账单、资产、健康、健身、待办、自知小记的所有业务数据都通过 SwiftData 存放在你的设备本地以及你 Apple ID 名下的 iCloud 私有数据库。即使本 App 停止运营，你的数据也完整保留在你的设备和 iCloud 中。

### 如何在多台设备之间同步？

平生通过 Apple CloudKit 同步数据。请确认：① 所有设备登录同一个 Apple ID；② 系统「设置 → Apple ID → iCloud」中开启了"平生"；③ App 内「设置 → iCloud 同步」处于开启状态。三者满足后，数据会在设备间自动同步。首次同步可能需要 1–2 分钟。

### AI 截图记账识别不准怎么办？

在记一笔时点击"截图识别"，AI 会自动填好金额、时间和分类，<strong>请务必在保存前核对一遍关键信息</strong>。原始图片不会被持久保留。如果识别明显偏差，欢迎在「设置 → 应用反馈」附上截图发给我们，我们会持续改进识别效果。

### AI 自知小记会用到我哪些数据？

"自知"模块可以一键生成<strong>周记 / 月记</strong>，AI 帮你从过去一段时间的账单、训练、饮食、待办里找 highlights、模式和值得追问的问题。首次使用前会显式征求你的同意，每天有调用次数上限。整个过程<strong>不会发送原始图片、不会发送跟健康/位置相关的敏感原始数据</strong>，只发送你已选模块的简要文本。

### 饮食 / 健身有哪些内置数据？

饮食模块内置 <strong>45 道</strong>常见食物（覆盖主食、肉蛋奶、海鲜、蔬菜、水果、豆类等），每条带营养值与图标，可直接快速记录，也可创建自定义食物。健身模块内置 <strong>83 个</strong>标准训练动作（胸 11 / 背 12 / 肩 10 / 手臂 14 / 腿 15 / 核心 10 / 有氧 12），按重量+次数 / 次数 / 时长 / 距离四种追踪类型自动适配；你可以基于动作自由组合训练计划。

### 健康 / 饮食环的数据来自哪里？

活动环来自 Apple Health 的活动量 / 运动 / 站立数据；饮食环来自 App 内饮食模块记录的蛋白 / 碳水 / 脂肪宏量营养素。可在系统「健康 App → 数据访问与设备 → 平生」精细管理 App 对 HealthKit 的读写权限。

### 快捷指令 / 锁屏小组件支持什么？

目前内置两个 App Intent：<strong>「快速添加待办」</strong>（可挂语音 + 自然语言）和 <strong>「截图记账」</strong>（不打开 App 即可识别并保存账单）。锁屏 / 主屏小组件提供"一键添加待办"。可通过快捷指令、语音助理、控制中心等多种方式触发。

### 支持哪些设备和系统？

平生目前支持 iPhone，需要 iOS 17 及以上。登录同一个 Apple ID 的设备共享同一份 iCloud 数据。

### 可以导出我的数据吗？

可以。会员可在「设置 → 通用 → 导出数据」选择模块（财务、健康、待办、日子、自知）和时间范围，导出为一个 .json 文件，再通过系统分享发给 ChatGPT、Claude 等 AI 助手分析，或存到「文件」。导出文件暂不支持导回 App。

### 如何删除我的所有数据？

卸载平生会删除所有本地数据。如需同时清除 iCloud 中的数据，前往 iPhone 的「设置 → Apple ID → iCloud → 管理账户储存空间」，找到"平生"并删除其数据。
