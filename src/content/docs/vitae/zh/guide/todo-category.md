待办也能按分类整理。你可以<strong>启用 / 禁用</strong>内置分类，只留用得上的；也能<strong>新建自己的分类</strong>，起个名字、选个颜色——之后记待办时就能归到它名下，列表里一眼分清。

## 操作步骤

1. <strong>进入分类管理</strong>。路径：<strong>设置 → 待办 → 分类管理</strong>，这里能启用 / 禁用分类、添加自定义分类。
2. <strong>启用 / 禁用分类</strong>。把分类的开关关掉，它就不在新建待办时出现；需要时再打开。
3. <strong>添加分类</strong>。点<strong>「添加分类」</strong>，输入分类名称（比如「上班任务」），点<strong>「下一步」</strong>。
4. <strong>选颜色</strong>。给分类挑一个颜色（用来在列表里区分），点<strong>「完成」</strong>保存。
5. <strong>开始使用</strong>。新分类立刻可用，记待办时就能选到它。

## 常见问题

### 禁用一个分类，原来归在它名下的待办会丢吗？

不会。禁用只是让它<strong>不在新建待办时出现</strong>，已有的待办和记录都还在。重新启用就又能用了。

### 分类的颜色或名字能改吗？

能。回到 <strong>设置 → 待办 → 分类管理</strong>，点开对应分类就能改名字、换颜色。

### 自定义分类能删掉吗？

能。在分类管理里删除即可。如果担心影响已记的待办，也可以只把它<strong>禁用</strong>而不删除。

### 怎么给待办指定分类？

新建或编辑待办时选择分类即可；用语音速记时 AI 还会自动判断分类，见 [语音速记待办](/vitae/guide/todo-voice/)。
