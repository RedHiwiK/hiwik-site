平生内置了一套<strong>动作库</strong>，覆盖胸、背、肩、臂、腿、核心、有氧各个部位，每个动作都标好了<strong>训练部位</strong>和<strong>计量方式</strong>。你可以按部位快速筛选、把动作加进训练计划；动作库里没有的，也能<strong>自己创建</strong>。

## 一、按部位浏览与筛选

在<strong>健康 → 锻炼</strong>里编排计划、点「+」添加动作时，就会进入动作库。顶部一排标签——<strong>全部 / 胸 / 背 / 肩 / 臂 / 腿 / 核心 / 有氧</strong>——点一下就只看那个部位的动作，也可以用上方搜索框直接搜动作名。

- <strong>训练部位</strong>：每个动作左下角的灰色标签（胸、背、肩……），方便按目标肌群挑。
- <strong>计量方式</strong>：右边的蓝色标签表示这个动作怎么记——<strong>重量×次数</strong>（杠铃、哑铃类）、<strong>次数</strong>（卷腹、健腹轮）、<strong>时间</strong>（平板支撑、战绳）、<strong>距离×时间</strong>（骑行）。
- <strong>加入计划</strong>：点动作右侧的蓝色<strong>「+」</strong>，就把它加进当前训练计划。

## 二、创建自定义动作

动作库里没有你想练的动作？点动作库<strong>右上角的「+」</strong>就能新建一个：填动作名、选训练部位、选计量方式，保存后它就和内置动作一样，能加进任意计划。

建好的自定义动作统一在 <strong>设置 → 健康 → 自定义动作管理</strong> 里查看和删除。

## 三、健身相关设置

到 <strong>设置 → 健康</strong>，有几个和健身有关的开关：

- <strong>动作示意图性别</strong>：切换男性 / 女性的动作示意图，挑你看着顺眼的。
- <strong>休息结束提醒</strong>：组间休息倒计时结束时是否发通知提醒。
- <strong>自定义动作管理</strong>：管理你创建的自定义训练动作。

## 常见问题

### 计量方式选错了能改吗？

能。在 <strong>设置 → 健康 → 自定义动作管理</strong> 里找到那个动作重新编辑即可（内置动作的计量方式是固定的）。

### 示意图能换成女性版吗？

能。到 <strong>设置 → 健康 → 动作示意图性别</strong> 切到「女性」，全部动作示意图都会跟着换。

### 自定义动作能加到计划里吗？

能。建好后它会出现在动作库里，和内置动作一样，编排计划时点「+」加进去就行。怎么编排见 [编排训练计划 + 开始训练](/vitae/guide/fitness-plan/)。
