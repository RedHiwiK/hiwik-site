# Vitae 2.0.0 官网发布准备

本分支用于配合 App Store 2.0.0 上线。发布、发起官网 MR 和合并均等待用户通知，不启用自动合并。

## 已准备

- 官网 App 图标与 2.0.0 默认图标一致，首页、导航及总览通过共享 App 配置引用。
- 中英文产品介绍、身体／饮食／训练指南和支持说明对齐新版功能。
- 中英文更新日志保留“待发布 / Unreleased”，不提前写上线日期。
- 隐私政策和介绍中的隐私承诺沿用 main；原工作目录中的隐私修订草稿不纳入此分支。

## 接到发布通知后

1. 回查 App Store 审核与构建状态，按用户指示合并 App MR 并执行发布。
2. 以实际 App Store 上线日期替换中英文更新日志的待发布标记。
3. 运行 pnpm build，发起官网 MR；经用户指示合并 main 后由现有工作流部署。
4. 核对线上新版图标、产品介绍、指南和更新日志。

历史活动海报和教程截图是独立素材；本分支沿用现有图片，涉及旧界面的饮食、训练演示已在指南中提示。
